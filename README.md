# 🌉 진로브릿지 (JobBridge)

> **"나만의 꿈을 향한 입시와 진로의 완벽한 연결 고리"**  
> 진로브릿지는 학생들의 학교 활동 기록, 성적 데이터 분석, 진로 흥미 검사, 직업·학과 검색을 통해 중·고등학생들의 맞춤형 진로 로드맵 설계를 돕는 **통합 진로·입시 네비게이션 서비스**입니다.

---

## 🔗 서비스 정보

* **서비스명**: 진로브릿지 (JobBridge)
* **서비스 URL 주소**: `https://<your-github-username>.github.io/jobbridge/`  
  *(※ `<your-github-username>` 부분에 본인의 깃허브 아이디를 넣으면 바로 접속이 가능한 웹 서버 주소가 됩니다.)*
* **서비스 한 줄 요약**: 학생 활동 기록과 커리어넷 학교·직업·학과 API 정보를 연결하여 학교 탐색, 직업·학과 검색, 포트폴리오 정리, ZEP 전시관 연결까지 한 번에 제공하는 정적 호스팅 대응 웹 어플리케이션.

---

## 🌟 주요 핵심 기능

### 1. 📊 통합 학생 포트폴리오 & 대시보드
* **진로 매개 변수 설정**: 학년, 내신/모의고사 성적, 희망 직무, 희망 학과, 자기소개 및 핵심 역량 키워드를 기록합니다.
* **활동 관리 다이어리**: 동아리, 대회, 독서 등 입력한 활동들이 포트폴리오 대시보드 카드와 히스토리 타임라인에 저장됩니다.
* **진로 미션 투두(TODO)**: 매일의 진로 활동 목표를 체크하며 달성도를 직관적으로 파악합니다.

### 2. 🧭 통합 진로·입시 포털 (Explore Portal)
* **고입 탐색기**: 커리어넷 학교정보 API에서 고등학교를 불러오고 학교명, 지역, 고교 유형, 관심 계열로 검색합니다.
* **대학교 정보 검색**: 커리어넷 학교정보 API에서 대학교명, 지역, 학교종류, 주소, 홈페이지 정보를 확인합니다.
* **진로 흥미 검사 & 체험활동 탐색**: 36문항 5점 척도 검사를 통해 현실형, 탐구형, 예술형, 사회형, 진취형, 관습형 직업 흥미 유형을 확인하고 분야별 체험활동 예시를 살펴봅니다.
* **커리어넷 직업·학과 검색**: 커리어넷 직업백과 및 학과정보 API에서 실제 직업·학과 정보를 검색합니다. 검색된 정보의 **`[내 프로필로 등록]`** 단추를 누르면 마이페이지 희망 직무가 자동으로 변경 및 저장됩니다.
* **가입 진로 기초검사**: 최초 회원가입 시 18문항 흥미 검사, 세부 관심 분야, 선호 활동 방식을 입력해 학생 정보가 자동 설정됩니다.

### 3. 🗺️ 진로 로드맵 & 설계기 (Roadmap Planner)
* 사용자의 성적, 희망 분야, 흥미 역량을 조합하여 학기별 권장 과목, 추천 비교과 활동, 권장 도서가 체계적으로 매핑된 **맞춤형 시각화 로드맵**을 생성합니다.

### 4. 🔒 프리미엄 인증 화면 및 게스트 모드
* **하늘빛 글래스모피즘 UI**: 반투명 블러 효과의 프리미엄 로그인/회원가입 폼을 통해 회원가입 시 **아이디 중복 확인**, **비밀번호 재확인** 등 철저한 프론트엔드 검증 가드를 거칩니다.
* **안전한 게스트 모드**: 로그인하지 않은 일반 브라우징 모드에서는 개인 정보를 노출하지 않고 `"비회원"` 및 `"비"` 아바타 마스킹 하에 탐색 기능을 사용할 수 있으며, 저장 기능은 로그인 후 사용할 수 있습니다.

## 🛠️ 기술 스택 및 아키텍처

진로브릿지는 설치 및 운영 비용 없이 누구나 깃허브에서 바로 연동해 서비스할 수 있도록 **하이브리드 아키텍처**로 구현되었습니다.

* **Frontend**: HTML5, Vanilla CSS (Custom Variable 및 Glassmorphism 테마 적용), Vanilla JavaScript (ES6+)
* **Backend**: 없음 (정적 파일 실행 기준)
* **Database**: `localStorage` (브라우저 저장소 기반)
* **정적 모드 저장 레이어**:
  - 정적 웹 호스팅 환경(GitHub Pages, 로컬 파일 직접 열기)을 자동으로 감지합니다.
  - 감지 시 `localStorage` 기반 저장 레이어로 전환하여, 서버 비용이나 지연 없이 100% 프론트엔드 내에서 구동됩니다.

## 🚀 시작하기 (How to Run)

### 방법 A: 파일 직접 열기 (권장)
1. 프로젝트 폴더에서 `index.html` 파일을 더블 클릭합니다.
2. 브라우저에서 열린 화면 그대로 서비스를 사용합니다.

### 방법 B: GitHub Pages를 이용한 무서버 서비스 구동
1. 이 프로젝트의 코드를 본인의 **GitHub Repository**에 업로드합니다.
2. 저장소의 **Settings > Pages** 메뉴로 이동합니다.
3. **Branch** 설정을 `main` (또는 `master`)으로 지정하고 **Save**를 클릭합니다.
4. 배포 완료 후 나타나는 `https://<username>.github.io/<repository>/` 링크로 바로 접속하여 서비스를 사용합니다.
